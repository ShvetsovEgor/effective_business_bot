# Геоаналитический модуль

Модуль помогает предпринимателю выбрать место под аренду или покупку. Он собирает конкурентов, модельные объявления и новостной фон адреса. Бот в MAX: **Хакатон МАХ 610**, `@t610_hakaton_max_bot`.

Модуль не заменяет просмотр помещения. Закрытые каталоги объявлений не используются. Там, где цифры модельные, это написано в данных и в ответе.

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Секреты лежат в `.env` и в git не входят:

```
MAX_BOT_TOKEN=
API_ORG_SEARCH_YANDEX=
YANDEX_AI_STUDIO_API_KEY=
```

`YANDEX_CLOUD_API_KEY` можно указать вместо `YANDEX_AI_STUDIO_API_KEY`. Каталог и модель по умолчанию: `b1gv2rfr13cpst5o42jr`, `aliceai-llm/latest`. Их перекрывают `YANDEX_CLOUD_FOLDER` и `YANDEX_CLOUD_MODEL`.

## Модули

### `bot.py`

Проверочный бот MAX. Команды `/start`, `/help`, `/ping`, остальной текст повторяет. Геоаналитику в диалог пока не считает.

Нужен `MAX_BOT_TOKEN`. Запросы идут на `https://platform-api2.max.ru`, сертификаты Минцифры лежат в `certs/`.

```bash
python3 bot.py
```

```bash
docker build -t max-bot .
docker run --env-file .env max-bot
```

Если у бота включён webhook, long polling не стартует.

### `yandex_map` — виджет подбора места

Работает только по Казани.

```bash
python3 -m yandex_map.server
```

Страница: http://127.0.0.1:8766/. Сервер должен иметь доступ в интернет: к Яндексу, AI Studio и при первом запуске к Overpass.

Первый экран — свой prompt-box. Сайдбар, карточки мест и организаций после него собраны из [MAX UI](https://github.com/max-messenger/max-ui) (`@maxhub/max-ui`) в `yandex_map/panel.js`.

1. Пользователь описывает бизнес обычным текстом.
2. Модель Alice разбирает описание в JSON: формат, сделка, бюджет, площадь, чек, районы и запросы для поиска конкурентов. Если модель недоступна, срабатывает разбор по ключевым словам.
3. На карту ложится тепловая карта модельной проходимости.
4. Из модельных объявлений отбираются подходящие по типу помещения и сделке. Объявления дороже бюджета больше чем на 30 % отсекаются, если остаётся хотя бы пять вариантов.
5. У десяти лучших по черновому баллу API Поиска по организациям ищет прямых конкурентов в радиусе из запроса. В счёт идут организации, у которых основная рубрика совпадает с форматом бизнеса.
6. Итоговый балл: проходимость 30 %, экономика 35 %, конкуренция 20 %, соответствие запросу 15 %. Показывается топ-5.
7. Для каждого места нейропоиск собирает новости улицы и района, а модель Alice даёт вывод: подходит, осторожно или не брать, с плюсами, рисками и важными новостями.

Эндпоинты: `GET /api/heat`, `GET /api/offers`, `POST /api/analyze` с `{"text": "..."}`, `POST /api/insight` с `{"brief": {...}, "place": {...}}`.

### `analysis`

Логика виджета.

- `footfall` — пешеходный поток по гексагонам из `yandex-geoanalytics-hexes.json`: `hex_id` это ячейка H3 разрешения 7, `pedestrian_traffic_day` — проходы в сутки. Индекс места — перцентиль его гексагона. Прежняя модель по OpenStreetMap остаётся для обновления кэша: `python3 -m analysis.footfall`.
- `brief` — разбор описания бизнеса в JSON.
- `competitors` — поиск конкурентов через API Поиска по организациям. Ключ в кабинете ограничен сайтом `yandex.ru`, поэтому запрос идёт с заголовком `Referer`. Ответ держится в памяти процесса и на диск не пишется.
- `finance` — модель «проходимость × аренда»: прохожие, доля покупателей, предел посетителей по площади, чек, маржа, расходы, аренда, прибыль и окупаемость. При покупке помещение в месяц стоит 1 % цены. Все коэффициенты — допущения MVP.
- `ranking` — отбор объявлений и итоговый балл.
- `insight` — новости района и вывод о целесообразности открытия.

### `osm_food`

Общепит Казани из OpenStreetMap: кафе, рестораны, бары, фастфуд, пабы, фудкорты. Имя берётся из тега `name`, координата принадлежит самой точке. Улица и дом есть только если их заполнили в OSM. Гексагоны H3 группируют точки и не измеряют проходимость.

```bash
python3 -m osm_food --h3-res 9 --out data/out
```

Пишет `places.geojson`, `hexes.geojson`, `places.csv` и `map.html`.

### `commercial_sim`

29 вымышленных объявлений коммерческой недвижимости Казани: аренда и продажа стрит-ритейла, офисы и склады. Ставки подогнаны к опубликованным средним на март 2026 года. Каждая запись помечена `data_origin=simulated`.

```bash
python3 -m commercial_sim
```

Файлы: `data/simulated/kazan_commercial.geojson`, `kazan_commercial.csv`, `map.html`.

### `llm`

Короткий запрос к модели Alice через OpenAI-совместимый API Yandex AI Studio.

```python
from llm import complete

print(complete("текст запроса", instructions="как отвечать"))
```

### `neurosearch`

Нейропоиск по пересечению улиц рядом с точкой: новостные сводки и выводы, что из них следует для открытия точки общепита или торговли. Ответ сопровождается источниками.

```bash
python3 -m neurosearch "Казань, улица Баумана, 42"
```

```python
from neurosearch import analyze_address

result = analyze_address("Казань, улица Баумана, 42")
print(result.text)
```
