## Как зафиксировать сдачу

После согласования и коммита материалов:

```bash
git status --short
git rev-parse HEAD
```

Первая команда должна показать отсутствие незакоммиченных сдаваемых изменений. Хеш второй сохранить **в заявке организаторам** вместе со ссылкой на репозиторий. Записывать его в тот же коммит не требуется: изменение документа меняет хеш.

Если нужен архив, создавать его из коммита, а не копированием рабочей папки с `.env`:

```bash
git archive --format=zip --output=../business-start-submission.zip HEAD
```

Контрольная сумма в PowerShell:

```powershell
Get-FileHash ../business-start-submission.zip -Algorithm SHA256
```

Проверить содержимое перед отправкой. Секреты для проверки передавать отдельно по согласованному защищённому каналу. После дедлайна сохранять сдаваемый коммит неизменным; новые изменения не выдавать за исходную сдачу.
